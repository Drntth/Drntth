# Projektötletek technológiák szerint

Az alábbiakban összegyűjtöttem néhány projektötletet, amelyek a szakmai önéletrajzomban felsorolt technológiák és programnyelvek felhasználásával valósíthatók meg. Ezek mind relevánsak lehetnek GitHub-projektként, és jól mutatnak egy fejlesztői portfólióban.

## 1. AI Chatbot webalkalmazás

- **Technológiák:** Python, Django, SQLite, JavaScript
- Egyszerű, tanítható chatbot, amely képes válaszolni felhasználói kérdésekre, admin felülettel és REST API-val.

## 2. Feladatkezelő alkalmazás

- **Technológiák:** C#, .NET, PostgreSQL, Bootstrap
- Felhasználók regisztrációja, feladatok létrehozása, státuszkezelés, jogosultságok, reszponzív webes felület.

## 3. Személyes pénzügyi menedzser

- **Technológiák:** Java, Spring Boot, MySQL
- Kiadások, bevételek nyilvántartása, grafikonok, riportok, felhasználói hitelesítés.

## 4. Online jegyzetelő

- **Technológiák:** PHP, Laravel, SQLite, Markdown
- Jegyzetek készítése, szerkesztése, címkézés, exportálás Markdown formátumban.

## 5. PlantUML diagram generátor webes felülettel

- **Technológiák:** JavaScript, Node.js, PlantUML, Docker
- Felhasználó feltölthet szöveges leírást, amiből automatikusan UML diagramot generál a backend.

## 6. Egyszerű blogmotor

- **Technológiák:** Python, Django, HTML5, CSS3
- Bejegyzések, kommentek, admin felület, keresés, kategóriák.

## 7. GitHub Actions workflow sablonok

- **Technológiák:** YAML, Bash
- Automatikus tesztelés, build, deployment sablonok különböző nyelvekhez.

## 8. Oktatási segédanyag generátor

- **Technológiák:** Jupyter Notebook, Python, Markdown
- Kódpéldák, magyarázatok, automatikus PDF/HTML export.

## 9. Webes időpontfoglaló rendszer

- **Technológiák:** JavaScript, Bootstrap, PHP, MySQL
- Időpontok foglalása, adminisztráció, email értesítések.

## 10. Adatvizualizációs dashboard

- **Technológiák:** Python, Django, JavaScript, Chart.js
- Feltöltött adatokból interaktív grafikonok, statisztikák.
